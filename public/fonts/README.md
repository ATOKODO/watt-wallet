# Bundled fonts

Watt Wallet shares Inter (UI), Lora (headings) and Roboto Mono (code) with its Figma file. Normal Latin and Latin Extended WOFF2 faces are self-hosted; no remote font request is made at runtime. These files are included in the service worker cache and in the desktop bundle.

Source: Fontsource packages @fontsource/inter, @fontsource/lora and @fontsource/roboto-mono, version **5.3.0**. See [Fontsource self-hosting documentation](https://fontsource.org/docs/getting-started/install).
