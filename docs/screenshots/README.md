# Captures Walletricity

Captures de viewport PNG pour le README, avec une galerie HTML et un manifeste par série.

| Appareil              | Dimensions  | Français                          | English                           |
| --------------------- | ----------- | --------------------------------- | --------------------------------- |
| iPhone 16 Pro         | 402 × 874   | [FR](iphone-16-pro/README.md)     | [EN](iphone-16-pro/en/README.md)  |
| iPad Pro 11 pouces    | 834 × 1194  | [FR](ipad-pro-11/fr/README.md)    | [EN](ipad-pro-11/en/README.md)    |
| MacBook Pro 14 pouces | 1512 × 982  | [FR](macbook-pro-14/fr/README.md) | [EN](macbook-pro-14/en/README.md) |
| Desktop               | 1920 × 1080 | [FR](desktop/fr/README.md)        | [EN](desktop/en/README.md)        |

Chaque série contient 21 captures. Démarrer l’application, puis utiliser `node scripts/screenshots-mobile.mjs [fr|en]` pour l’iPhone ou `node scripts/screenshots-devices.mjs` pour les autres formats. Les arguments facultatifs sélectionnent un appareil et une langue.
